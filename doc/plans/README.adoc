== Packages

[#how]
== How to Work a Package

As link:../../../plan-marshall-documentation/doc/developer/project-setup.adoc#_planning_the_work[Project Setup § Planning the Work] states. The Done When of a package includes the builds of this repository (`verify`, `verify -Ppre-commit` with its rewrites committed, `verify -Pcoverage`, `verify -Pintegration-tests`, and the native build where the package touches a binary), and the package keeps its documents where `CLAUDE.md` places them.
