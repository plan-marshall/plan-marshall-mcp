== What

* The model verification corpus is validated by the build and shipped with the release as the input of `pm-operator roles qualify`. The validation is the Java validator of link:https://github.com/plan-marshall/pm-mcp-core/blob/603d4f7/doc/plans/corpus-sources.adoc[`pm-mcp-core` / `corpus-sources`], run by a JUnit test of pm-mcp-server in the regular build over the corpus's own items, the manifests, and the overlays; `test/model/verification/validate.py` is retired with it, and the corpus README says so.
* What ships is the corpus's own items, the source manifests, and the overlays; third-party datasets are fetched at their pinned commit by `pm-operator roles qualify` and never shipped, and a source that cannot be fetched leaves the qualification on a subset that its record names (link:https://github.com/plan-marshall/plan-marshall-mcp/blob/5481521/doc/plans/question-corpus-public-datasets.adoc[`question-corpus-public-datasets`]).
