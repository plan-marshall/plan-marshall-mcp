== Tasks

* The model verification corpus is validated by the build and shipped with the release as the input of `pm-operator roles qualify`. The validation is the Java validator of the done package `pm-mcp-core` / `corpus-sources`, run by a JUnit test of pm-mcp-server in the regular build over the corpus's own items, the manifests, and the overlays; `test/model/verification/validate.py` is retired with it, and the corpus README says so.
* The release ships the corpus's own items, the source manifests and the overlays, never a third-party dataset: link:../../../pm-mcp-core/doc/specification/model-work/01-roles-and-configuration.adoc#corpus-sources[Model Work § Corpus Sources].
