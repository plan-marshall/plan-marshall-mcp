= The harness named as the documents name it
:nofooter:

link:README.adoc[Work packages of `plan-marshall-mcp`] » `harness-names`

[horizontal]
Where:: pm-mcp-server packages `mcp.server.tools`, `mcp.server.security`; pm-e2e
Status, milestone and dependencies:: in the link:README.adoc#packages[index], the only place that states them

The documents name the coding agent that runs workers the _harness_; _host_ means only the machine. The code of this repository still says _host_ for the harness in its documentation and test names. The renames change no behaviour; the removal of the session relay removes two wire headers that only that mode sent.

== Tasks

* The class documentation and display names that say _host_ for the harness say _harness_: `SessionlessInitialize` (a session-opening harness, link:../../../plan-marshall-documentation/doc/specification/runtime-model/03-relay.adoc[Runtime Model § Relay]), `McpSurfaceIT` (`serves both harness forms`), `StdioPeer` (as a harness speaks to its MCP server). _Host_ for the machine (the loopback listener, the `Host` header, `PM_MCP_HOME`) stays.
  Proof: `git grep -w -i host` over `pm-mcp-server/src` and `pm-e2e/src` finds only the machine and the HTTP `Host` header.
* The harness session through the relay is removed, because the specification has none (a harness is a worker only, and `pm-mcp` has the one verb `serve --job`, link:../../../plan-marshall-documentation/doc/specification/cli-and-security/01-cli-and-installer.adoc#command-tree[CLI, Coordination & Security § Command Tree]): the session headers `PM-MCP-Client` and `PM-MCP-Host-Marker` (`IdentityAttributes.SESSION_HEADERS`) and their reading leave `pm-mcp-server`; `ReleaseLayoutIT` and `StdioHarnessIT` run their round trip through `pm-mcp serve --job` with a job token instead of `serve --client neutral`.
  Proof: `TokenAuthenticationMechanismTest` and `McpSocketTest` have no session-header case and refuse nothing that only the session mode sent; `git grep -e PM-MCP-Client -e PM-MCP-Host-Marker` finds only `PM-MCP-Client-Info` and `PM-MCP-Client-Capabilities` of the relay rules.
