== What

HumanEval is in the training data of most models. A model that recalls the original problem may proceed on a modified one instead of asking, and then `question/ask-or-proceed` measures recall, not asking. This package measures, per model, how often it asks on the modified variants of link:question-corpus-public-datasets.adoc[`question-corpus-public-datasets`] against how often it asks on their controls, and decides per category whether the category stays in the corpus.

* *Run*: the generated items of `question/ask-or-proceed` (the corpus test's import, never a copy) offered fresh to each model, one item per session, through the task protocol's single submit with the item's choices; Claude Code with `claude-haiku-4-5` and `claude-sonnet-5-5`, OpenCode with the model the shipped default assignment names for `worker`; 5 runs per item and model.
* *Measured*: per model and category the ask rate on the modified variants, on the controls, and the difference with its 95 % interval; the tokens per item.
* *Decision per category*: a category whose ask rate is not above its controls' for any model (the interval of the difference includes 0) is reported in the README and its items set `review.status: contested` in the overlay, with the measurement in `review.notes`; they are not deleted. A category that differs stays.
* *Recorded*: the table in `test/model/verification/README.adoc` (§ Ask rate), with the date, the corpus revision, the models and their versions, and the run count.
