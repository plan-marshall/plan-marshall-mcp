== What

* CDI producers of the stores, the engine and the plan instance services of `pm-core` and `pm-workflow`; the first dependency of `pm-mcp-server` on `pm-workflow`.
* The registration of the persisted records for native reflection, with the build test that every persisted record of the library modules is registered.
