== Tasks

* An `initialize` without `Mcp-Method` receives no `Mcp-Session-Id` either.
* The component tests use the sessionless form. Today they reach the daemon with `McpAssured` over the loopback TCP listener that the test profile opens. Settle first, in the trace matrix, how they reach it without TCP: `McpAssured` over the Unix socket if `quarkus-mcp-server-test` offers that transport, otherwise MCP calls through the socket client of `pm-api`. Only then is the loopback listener of the test profile removed; if neither works, stop and correct the roadmap item with the evidence.
* The tests of the filter and of the silent `subscriptions/listen` stream are the ones every upgrade of `quarkus-mcp-server` re-runs.
